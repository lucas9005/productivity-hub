# 🚀 Productivity Hub — Frontend Scripts Reference

## `ng`

```sh
ng
```

> Shortcut to invoke Angular CLI.

## `start:dev`

```sh
bun run start:dev
```

> Start the Angular app using the development configuration with live reload.

## `start:prod`

```sh
bun run start:prod
```

> Start the Angular app using the production configuration with live reload.

## `build:dev`

```sh
bun run build:dev
```

> Build the Angular app using the development configuration.

## `build:prod`

```sh
bun run build:prod
```

> Build the Angular app using the production configuration.

## `build:dev:watch`

```sh
bun run build:dev:watch
```

> Build the Angular app on changes using the development configuration.

## `build:prod:watch`

```sh
bun run build:prod:watch
```

> Build the Angular app on changes using the production configuration.

## `test:unit`

```sh
bun run test:unit
```

> Run unit tests using Jest.

## `test:unit:watch`

```sh
bun run test:unit:watch
```

> Run unit tests with live reload.

## `test:unit:coverage`

```sh
bun run test:unit:coverage
```

> Run unit tests and generate code coverage report.

## `test:unit:ci`

```sh
bun run test:unit:ci
```

> Run unit tests in CI mode with sequential execution and generate code coverage report.

## `test:e2e`

```sh
bun run test:e2e
```

> Run e2e tests using Playwright.

## `test:e2e:ui`

```sh
bun run test:e2e:ui
```

> Run e2e tests using Playwright with interactive UI.

## `test:e2e:debug`

```sh
bun run test:e2e:debug
```

> Run e2e tests in debug mode with full tracing and inspector support.

## `test:e2e:report`

```sh
bun run test:e2e:report
```

> Serve the execution report generated by the last e2e test run.

## `test:e2e:ci`

```sh
bun run test:e2e:ci
```

> Run e2e tests in CI mode with a real browser and configured reporting.

## `docs`

```sh
bun run docs
```

> Build and serve the Angular documentation using Compodoc.

## `docs:build`

```sh
bun run docs:build
```

> Build the Angular documentation using Compodoc.
