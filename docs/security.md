# 🚀 Productivity Hub — Security Overview

## Code Scanning and Static Analysis

- GitHub Actions is configured to run **CodeQL security scans** on every push and pull request targeting the `dev` branch.
- CodeQL currently analyzes JavaScript source code for potential vulnerabilities.
- Results are available in the GitHub Security tab and as checks on pull requests into the `dev` branch.
- Code scanning currently focuses on JavaScript and its ecosystem; future expansions can add additional languages if needed.
